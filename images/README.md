# Thư viện hình ảnh

- `branding/brand-logo.png`: logo gốc của trò chơi.
- `players/player-avatar.png`: avatar minh họa người chơi.
- `dice/faces/face-1.webp` đến `face-6.webp`: sáu mặt xúc xắc khi đứng yên.
- `dice/rolling/frame-01.webp` đến `frame-09.webp`: các khung hình xúc xắc đang lăn; game lần lượt đổi ảnh để tạo hoạt ảnh.
- `dice/legacy-dice-grid.png`: sprite xúc xắc cũ, giữ làm bản tham khảo; game hiện không tải file này.

`public/assets/` chứa các bản game tải trực tiếp. Các mặt và khung xúc xắc trong `public/assets/dice/` được sao chép từ `images/dice/`.
